# portfolio.dev

My personal portfolio: experience, projects, tech stack, and a small car game in case you get bored.

**→ [maxi-andres.github.io/portfolio.dev](https://maxi-andres.github.io/portfolio.dev/)**

Built with React, TypeScript, Vite, Tailwind CSS and three.js. Every push to `main` is deployed to GitHub Pages automatically.

## Run it locally

```bash
pnpm install
pnpm dev
```
